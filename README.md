# 무료아카데미월드

학원에서 무료로 쓸 수 있는 자료(평가원·교육청 기출, 공식 배포 모의고사, 무료 강의, 수업 도구, 무료 AI)를 과목별·공통으로 모은 정적 웹사이트입니다.

## 구성

- `index.html`: 사이트 전체(데이터 포함, 빌드 불필요). 브라우저로 바로 열거나 GitHub Pages로 배포합니다.
- `src/page.html`: 같은 내용의 본문(미리보기용). 자료를 고칠 때는 두 파일의 `const R = [...]` 목록을 함께 고치세요.

## 자료 추가 방법

`const R` 배열에 한 줄을 추가합니다.

```js
["과목ID", "이름", "운영 기관", "https://주소", "한 줄 설명", "종류", "무료범위"]
```

- 과목ID: `exam` `common` `korean` `math` `english` `science` `social` `coding` `ai` `class` `career`
- 종류: `기출` `모의고사` `강의` `도구` `AI` `자료`
- 무료범위: `free`(완전 무료), `join`(무료·회원가입), `plan`(무료 요금제, 일부 유료)

## 수록 원칙

- 기관·제작자가 공식적으로 무료 공개한 페이지의 **링크만** 모읍니다. 파일을 직접 올리거나 재배포하지 않습니다.
- 사설 모의고사는 제작자가 배포 조건을 밝힌 게시판(오르비, 수만휘 등)으로만 연결합니다.
